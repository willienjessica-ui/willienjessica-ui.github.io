API Wallet Privacy Policy

Effective Date: May 29, 2026

API Wallet is operated by Morris Lane LLC.

API Wallet helps users manage API credentials, AI provider connections, usage tracking, budget limits, and local application settings.

API Wallet may store user-entered API keys, app settings, provider configuration, usage records, and budget preferences. This information is used only to operate the app’s features.

API Wallet is designed to store sensitive information locally on the user’s device unless the user chooses to connect external services.

Users may connect third-party providers including OpenAI, Google Gemini, Anthropic Claude, and xAI Grok. Data sent to those services is governed by each provider’s own privacy policy and terms.

Morris Lane LLC does not sell user data and does not share user data with advertisers.

API Wallet is not directed to children under 13 and does not knowingly collect personal information from children.

Users may remove API keys, clear local data, and uninstall the app at any time.
