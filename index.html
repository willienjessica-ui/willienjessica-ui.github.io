Roadmap To The Metaverse Mall

The metaverse is the end game. The current build has to earn it: real commerce first, then vendor storefronts, then programmable districts with Debbie governance.

Phase 1

Correct Static Storefront

Red, white, blue, navy, steel, product lanes, Fast Lane CTA, Digital Steel teaser, and honest static GitHub Pages deployment.

Phase 2

Marketplace Prototype

Next.js storefront, product detail pages, cart state, category search, product data, and checkout plumbing before live payment claims.

Phase 3

Storefront Deed Layer

Base testnet contract, deed slots, mint page, on-chain counters, vendor dashboard access, and Supabase deed sync before any mainnet launch.

Phase 4

Vendor Commerce Splits

Stripe Connect onboarding, vendor products, platform fee routing, order records, payout status, and support flows Debbie can answer.

Phase 5

Digital HOA Districts

District configs, public rules, quality scoring, treasury ledger, appeals, Debbie governance receipts, and transparent enforcement history.

End Game

Full Metaverse Mall

3D storefront slots around the Morris Lane anchor tenant, vendor interiors, digital products, physical goods, and district-level commerce automation.

Storefront Deed Pipeline

  • 1Mint deed on Base testnetHard-capped slots, live on-chain counter, and no mainnet launch before legal/audit gates.
  • 2Sync deed to SupabaseIndexer mirrors token ID, slot ID, owner wallet, phase, and transaction hash.
  • 3Unlock vendor dashboardWallet signature proves ownership, then vendor configures theme, logo, products, and storefront name.
  • 4Split vendor salesStripe Connect sends vendor payout while Morris Lane collects a platform fee.

Debbie Digital HOA Scope

District rules stay public. Debbie evaluates compliance, scores quality signals, writes appealable governance events, and produces signed receipts.

Programmable District Layer
